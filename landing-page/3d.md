# Guia de Integração 3D (Three.js + React)

Este documento detalha como os arquivos 3D foram inseridos no componente `TheBeeBoilerplate.tsx` e fornece instruções passo a passo para você replicar essa técnica em outros projetos.

## 1. Tecnologias Utilizadas

Para a renderização 3D, o projeto utiliza:
- **Three.js**: A biblioteca principal para gráficos 3D no navegador.
- **GLTFLoader**: Um plugin do Three.js para carregar arquivos no formato `.glb` ou `.gltf` (o padrão da indústria para web).
- **React Hooks**: `useRef` e `useEffect` para gerenciar o ciclo de vida do Three.js dentro do ecossistema React.

## 2. Estrutura do Arquivo 3D

O modelo da abelha está localizado em:
`landing-page/public/games/stranger-craft/models/bee.glb`

> [!TIP]
> Em projetos Next.js ou Vite, arquivos na pasta `public/` podem ser acessados diretamente pela URL, por exemplo: `/games/stranger-craft/models/bee.glb`.

## 3. Passo a Passo da Implementação

### A. Instalação de Dependências
Você precisará instalar o Three.js e seus tipos (se usar TypeScript):
```bash
npm install three
npm install -D @types/three
```

### B. Setup da Cena (O "Palco")
No componente, inicializamos os elementos básicos do Three.js dentro de um `useEffect`:

1.  **Cena (Scene)**: Onde tudo acontece.
2.  **Câmera (Camera)**: O ponto de vista do usuário.
3.  **Renderizador (Renderer)**: O motor que desenha os pixels no `<canvas>`.

No `TheBeeBoilerplate.tsx`, o renderizador é configurado com transparência:
```javascript
const renderer = new THREE.WebGLRenderer({
  alpha: true, // Permite fundo transparente
  antialias: true, // Suaviza as bordas
});
renderer.setClearColor(0x000000, 0); // Define o fundo como totalmente transparente
```

### C. Carregamento do Modelo (.glb)
Usamos o `GLTFLoader` para carregar o arquivo:

```javascript
const loader = new GLTFLoader();
loader.load('/games/stranger-craft/models/bee.glb', (gltf) => {
  const model = gltf.scene;
  model.scale.set(0.2, 0.2, 0.2); // Redimensiona o modelo
  scene.add(model); // Adiciona na cena
});
```

### D. Iluminação
Sem luz, o modelo ficará preto. No projeto, usamos uma combinação de:
- **AmbientLight**: Luz global que ilumina tudo igualmente (evita sombras pretas puras).
- **DirectionalLight**: Luz tipo "Sol", que cria sombras e profundidade.

### E. Loop de Animação
Para que o 3D se mova, precisamos de um loop infinito (`requestAnimationFrame`):

```javascript
const animate = () => {
  const animationId = requestAnimationFrame(animate);
  // Exemplo: Faz a abelha flutuar (bobbing effect)
  if (playerRef.current) {
    const time = Date.now() * 0.001;
    playerRef.current.position.y = Math.sin(time * 3) * 0.2;
  }
  renderer.render(scene, camera);
};
animate();
```

## 4. Técnicas Avançadas usadas no projeto

- **Transparência**: O componente não tem fundo sólido, permitindo que ele se misture perfeitamente com o layout da página. Isso é feito via as flags `alpha: true` no renderer e `scene.background = null`.
- **Limpeza de Memória (Cleanup)**: No React, é CRÍTICO limpar os objetos Three.js quando o componente é desmontado para evitar vazamentos de memória (memory leaks). O projeto faz isso no `return` do `useEffect`, descartando geometrias, materiais e o próprio renderer.
- **Responsividade**: Um `resize handler` ajusta a proporção da câmera e o tamanho do renderer sempre que a janela muda de tamanho.

## 5. Como inserir em outro site (Checklist)

1. [ ] **Prepare o modelo**: Converta seu 3D para `.glb` (use o Blender ou ferramentas online).
2. [ ] **Adicione ao projeto**: Coloque o arquivo na pasta `/public`.
3. [ ] **Crie o componente**: Copie a estrutura de `TheBeeBoilerplate.tsx`, ajustando o caminho do modelo.
4. [ ] **Ajuste a Câmera**: Mude `camera.position.set(...)` e `model.scale.set(...)` até o modelo aparecer no tamanho certo.
5. [ ] **Estilize o container**: Garanta que a `<div>` que contém o canvas tenha largura e altura definidas (ex: `w-full h-[600px]`).

---

### Quer uma alternativa mais moderna?
Se você estiver usando React seriamente, recomendo o pacote **`@react-three/fiber`**. Ele permite escrever Three.js como componentes React:

```jsx
<Canvas>
  <ambientLight intensity={0.5} />
  <pointLight position={[10, 10, 10]} />
  <Model />
</Canvas>
```
No momento, o `TheBeeBoilerplate.tsx` usa **Vanilla Three.js**, o que é ótimo para entender os fundamentos, mas `@react-three/fiber` é mais produtivo para aplicações complexas.
